# 🛡️ InfoSec Pulse - Ethical Hacking Guide

An educational, responsive web portal built to introduce the fundamentals of cybersecurity and ethical hacking. This site functions as an interactive guide for beginners looking to understand safe, legal penetration testing concepts.

## ✨ Features

* **Cybersecurity Modules:** Organized sections covering Network Security, Web Application Pen-Testing, and Cryptography.
* **Interactive Code Blocks:** Styled syntax highlights using pure CSS to easily read terminal commands and scripts.
* **Pure CSS Theme:** A high-contrast "hacker-style" dark theme (matrix green/cyberpunk aesthetic) engineered entirely without heavy frameworks.
* **Fully Responsive:** Fluid grid layouts ensuring seamless readability across mobile devices, tablets, and desktops.
* **Disclaimers & Ethics Page:** Clear legal guidelines emphasizing the boundaries of authorized testing.

## 🛠️ Built With

* **HTML5** - Semantic layout structure (`<section>`, `<article>`, `<nav>`) optimized for web accessibility.
* **CSS3** - Custom properties (CSS variables), Flexbox/Grid for layout, and terminal text blinking animations.

## 🚀 Getting Started

To view and edit this cybersecurity portal locally, you only need a web browser and a code editor.

### Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Edem692/webcom
   ```

2. **Open the project:**
   Double-click the `index.html` file to view it instantly in your web browser.

   *Tip: If you use VS Code, use the **Live Server** extension to see edits refresh instantly as you type.*

---

## 🌐 Deployment to GitHub Pages

This project is structured for immediate deployment via GitHub Pages:

1. Navigate to your repository on **GitHub**.
2. Click on the ⚙️ **Settings** tab.
3. Scroll down the left sidebar and click on **Pages**.
4. Under **Build and deployment**, set the Source dropdown to **Deploy from a branch**.
5. Under **Branch**, select `main` (or `master`) and `/ (root)`. Click **Save**.
6. Wait 60 seconds and refresh the page to see your live secure URL link at the top.
